EICAS 故障信息显示（207 × 253）

左栏 147px / 右栏 60px · 五级警告 · 多页翻页 · CANCEL / RECALL

Display

页码 1/1 条目 0 状态 正常

Controls

快捷键：C = CANCEL（清除当前页并翻页，末页则清空显示），R = RECALL（恢复并回到第一页）。
默认字体为 Courier New 11px；行高、"·" 标识宽度会随字号自动调整，超出栏宽的文字自动截断为省略号 （右栏仅 60px，等宽 12px 已是上限，再大会开始截断）。

var eicas = new EICASFaultDisplay('eicas-screen');
var h = eicas.add(2, 'ELEC GEN 2'); // 2 级：黄色 + "·"
eicas.add(3, 'BUS TIE 2 OPEN', h); // 子条目：缩进显示
eicas.add(1, 'FIRE ENG R'); // 1 级：红色，常显置顶
eicas.add(4, 'OIL', null, 'right'); // 右栏（窄栏用短标签）
eicas.remove(h); // 连同子条目一起移除
eicas.setFont('Helvetica, Arial', 12); // 换字体（默认 Courier New 11px）

Message levels

  • L ENG FAIL 级别 1 · 红色，锁定在顶部，任何页都显示且不会被 CANCEL 清除
  • · HYD PRESS 级别 2 · 黄色，左侧带 “·” 标识
  • FLT CTRL 级别 3 · 黄色，无标识
  • FUEL PUMP 级别 4 · 白色
  • APU RUN 级别 5 · 绿色
条目按「级别升序 + 先来后到」排序；高级别条目下的低级别子条目缩进显示，且与父条目同页。 超过一屏时在下方显示 当前页/总页数；清空显示后再添加的新条目会自动显示出来。
